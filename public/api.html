REAL COMMAND API

← back to the game openapi.json rules catalog

Everything the web client can do is available through this REST API (and the WebSocket stream). Scripts and AI agents use it to build and run a base: register, pick a start position, deploy, produce, place buildings and command units.

Authentication: Authorization: Bearer <token>. Your token is shown in the game under API & KI. Coordinates can be given as x,y (metres) or lon,lat (degrees).
